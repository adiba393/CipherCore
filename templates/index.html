CipherCore

A hands-on implementation of classical and modern cryptographic algorithms.

Classical Cryptography
S
Substitution Cipher
Monoalphabetic substitution with a 26-letter permutation key. Includes frequency analysis and intelligent brute-force attack.
→
T
Double Transposition
Two-pass columnar transposition using row and column permutation keys, with step-by-step matrix visualization.
→
Symmetric-Key Cryptography
D
DES
Data Encryption Standard — 56-bit key, 16-round Feistel network with full key schedule and all round subkeys.
→
A
AES
Advanced Encryption Standard — AES-128 / 192 / 256 with Rijndael key expansion and all round keys displayed.
→
Public-Key Cryptography
R
RSA
Miller-Rabin prime generation, 64–2048-bit keys, and Pollard's Rho factorization attack demonstrated on small keys.
→
E
ECC + ECDH
Elliptic curve point arithmetic over GF(p), key pair generation, and Diffie-Hellman key exchange simulation.
→

This project was developed as part of the CSE721: Introduction to Cryptography course at BRAC University, Master's program.

All algorithms are implemented from scratch in Python — no cryptographic libraries used.

Security & Performance Analysis
Live Benchmark

Runs each algorithm 5 times on real input and measures average execution time. RSA key generation is excluded from timing as it involves probabilistic primality testing.

About the Benchmark
Input sizes: 16 bytes and 1 KB plaintext
Rounds: 5 iterations per algorithm, average taken
Metric: Wall-clock time in milliseconds
Platform: Pure Python, no native crypto libs
Note: results reflect Python overhead, not hardware-optimised performance. Real-world implementations (OpenSSL, etc.) are orders of magnitude faster.
